# GraphQL

For factual or version-sensitive GraphQL work, use [GraphQL Learn](https://graphql.org/learn/) or the [GraphQL specification](https://spec.graphql.org/) before answering. Open the smallest relevant page; do not load the full documentation corpus.

For API design, check the official best-practice guidance for schema design, authorization, pagination, error handling, performance, and security as relevant.
